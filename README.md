# echoping

**Лёгкий неофициальный клиент Telegram** на Rust и TDLib. Живёт в собственном окне (со значком в трее) и в терминале, потребляет мало памяти и умеет «режим невидимки».

*English: a lightweight, unofficial Telegram client written in Rust on top of TDLib. It runs in its own window (with a tray icon) or in a terminal, uses little RAM and has a "ghost mode". The UI language is Russian.*

> echoping не связан с Telegram и не одобрен им. Для работы нужны ваши собственные ключи API (см. ниже). Версия 0.1: проект молодой, возможны ошибки.

## Возможности

**Вход и аккаунты**
- Вход по QR-коду или по номеру телефона, облачный пароль (2FA), сохранение сессии.
- До 5 аккаунтов одновременно: переключение кликом по номеру внизу слева или `Ctrl+1..5`, у каждого аккаунта своя база.
- Демо-режим без аккаунта и без ключей (кнопка на экране входа или `--demo`).

**Чаты и сообщения**
- Список чатов с аватарками, непрочитанными, папками (Все, Личные, Группы, Каналы, Боты), избранным (★), архивом, закреплением сверху, поиском и вкладками.
- История, ответы, правка, удаление, отправка файлов и фото (кнопка `[@]`, `Ctrl+F` или перетаскивание файла в окно).
- В каналах, где вы только подписчик, поле ввода скрыто.
- Профили пользователей, групп и каналов (клик по имени в шапке или «Профиль отправителя»).
- Активные сеансы: просмотр, завершение, приём звонков и секретных чатов, автозавершение неактивных.
- Telegram Premium и Stars: статус, тарифы, баланс. Оплата проходит в официальном @PremiumBot.

**Медиа**
- Фото и кадры видео открываются прямо в клиенте.
- Голосовые сообщения воспроизводятся внутри клиента (декодер Opus на чистом Rust).
- Файлы скачиваются и сохраняются в папку «Загрузки» (меняется в настройках).
- Пиксельные эмодзи (Twemoji), панель эмодзи (`Ctrl+E`), подстановка `:fire:`.

**Приватность**
- Режим невидимки (`Ctrl+G`): не отправляет «прочитано» и «прослушано», при желании скрывает «в сети».

**Интерфейс**
- Размер интерфейса (`Ctrl+колесо`, `Ctrl+=`, `Ctrl+-` или настройки), ширина списка чатов (потяните границу мышью), размер подписей папок.
- Всё нажимается мышью; колесо листает списки и любые контекстные меню.
- Терминальная версия `echoping-tui` с тем же интерфейсом.

**Память**
- Режим «Экономия ОЗУ» (по умолчанию): без базы сообщений, без миниатюр, ленивая загрузка чатов и аватарок.
- В простое неиспользуемая память возвращается системе. Расход виден справа внизу («ОЗУ N МБ»).

## Чего нет
Аудио- и видеозвонков (в TDLib нет медиадвижка звонков), воспроизведения видео внутри клиента (показывается кадр, воспроизведение во внешнем плеере), секретных чатов, стикеров, реакций, опросов, форматирования текста, уведомлений. Многие пункты настроек пока только сохраняются и не влияют на Telegram.

## Быстрый старт
1. Получите ключи на [my.telegram.org](https://my.telegram.org): API development tools → Create application. Нужны `api_id` и `api_hash`.
2. Соберите (нужен [Rust](https://rustup.rs); в Windows ещё Visual C++ Build Tools):
   ```
   cargo run --release
   ```
   Сборочный скрипт сам скачивает готовую TDLib (около 50 МБ).
3. Введите ключи при первом запуске и войдите по QR или номеру.

Терминальная версия: `cargo run --release --bin echoping-tui`.

### Встроенные ключи (для сборщиков)
Если вы публикуете готовую сборку, можно зашить **свои** ключи, чтобы пользователям не приходилось вводить их:
```
set ECHOPING_API_ID=123456
set ECHOPING_API_HASH=0123456789abcdef0123456789abcdef
cargo build --release
```
В GitHub Actions задайте секреты `ECHOPING_API_ID` и `ECHOPING_API_HASH`. Ключи в готовом exe можно извлечь, это обычная практика для клиентов, но не используйте чужие ключи.
Без ключей Telegram не работает ни с одним клиентом, поэтому без них доступен только демо-режим.

## Управление
| Клавиши | Действие |
|---|---|
| `F1` | справка |
| `Ctrl+K` | поиск чатов |
| `Ctrl+1..5` | переключить аккаунт |
| `Ctrl+G` | режим невидимки |
| `Ctrl+O` | настройки |
| `Ctrl+E` | эмодзи |
| `Ctrl+F` | отправить файл |
| `Alt+P` / `Alt+A` | закрепить чат / в архив |
| `Alt+←` / `Alt+→` | ширина списка чатов |
| `F9` | отклонить входящий звонок |
| `Ctrl+Q` | выход |

ПКМ по чату открывает меню (профиль, закрепить, архив), ПКМ по сообщению открывает меню сообщения.

## Данные на диске
Windows: `%APPDATA%\echoping`, Linux/macOS: `~/.config/echoping`.
- `config.ini`: настройки и ваши `api_id` / `api_hash` (открытым текстом).
- `tdlib/`, `tdlib_2/` ...: сессии и кэш Telegram. **Папка даёт доступ к аккаунту: никому её не показывайте.**
- `avatars/<имя чата>.png`: собственная аватарка.

## Устройство проекта
- `src/app.rs` логика, `src/ui.rs` интерфейс, `src/td.rs` связь с TDLib, `src/render.rs` отрисовка в окне.
- `src/bin/echoping.rs` оконная версия, `src/bin/echoping-tui.rs` терминальная.
- `src/voice.rs` голосовые, `src/emoji.rs` эмодзи, `tools/gen_emoji.py` сборка атласа эмодзи.

Проверка без окна: `echoping --render-png out.png nologin key:ctrl-e` сохраняет кадр в PNG; `echoping-tui --dump nologin` печатает кадр текстом.
