# echoping

Клиент Telegram для терминала: интерфейс на [ratatui](https://ratatui.rs), связь с Telegram через официальную [TDLib](https://github.com/tdlib/td).
Версия **0.1.0** (ранняя, возможны ошибки).

> Неофициальный клиент. Для работы нужны собственные `api_id` и `api_hash`, их выдаёт Telegram.

## Возможности
- Вход по QR-коду, по номеру телефона с кодом, с облачным паролем.
- Список чатов, папки по типу чата, закрепление, архив, поиск, вкладки чатов.
- Отправка и получение текста, ответы, правка, удаление, отправка файла, скачивание вложений.
- Встроенный аудиоплеер для локальной музыки.
- Режим «невидимка» (Ctrl+G): не отмечает сообщения прочитанными и прослушанными, не шлёт «печатает», может скрывать «в сети».
- Активные сеансы (просмотр, завершение), просмотр тарифов Premium и баланса Stars.
- Управление мышью, экономия памяти (`Настройки > Память`).

## Сборка
Нужен [Rust](https://rustup.rs) (stable). При первой сборке скрипт скачивает готовую TDLib с GitHub (около 50 МБ).
На Linux для звука нужны заголовки ALSA (`libasound2-dev`), также `libssl` и `zlib`.

```
cargo run --release              # обычный запуск
cargo run --release -- --demo   # демо без аккаунта, на тестовых данных
cargo run --release -- --mouse-debug   # диагностика мыши
```

Сборка с уже установленной TDLib: `LOCAL_TDLIB_PATH=/путь/к/tdlib cargo build --release --no-default-features --features local`.

## Ключи API (один раз)
[my.telegram.org](https://my.telegram.org) > API development tools > Create application. Программа спросит `api_id` и `api_hash` при первом запуске.
Можно задать переменными окружения `ECHOPING_API_ID` и `ECHOPING_API_HASH`.

## Клавиши
| Клавиша | Действие |
|---|---|
| F1 | справка |
| Ctrl+K | поиск чатов |
| Ctrl+G | режим невидимки |
| Ctrl+O | настройки |
| F3 | плеер (F6/F7/F8: предыдущий, пауза, следующий) |
| Ctrl+F | отправить файл |
| Alt+P / Alt+A | закрепить чат / в архив |
| F9 | отклонить входящий звонок |
| Ctrl+Q | выход |

ПКМ по чату: закрепить / архив. ПКМ по сообщению: меню.

## Где хранятся данные
Windows: `%APPDATA%\echoping`, Linux и macOS: `~/.config/echoping`.
- `config.ini`: настройки и ключи API
- `tdlib/db`: сессия Telegram. **Никому не показывайте и не коммитьте.**
- `tdlib/tdlib.log`: журнал TDLib
- `avatars/<имя>.png`: своя аватарка для чата

## Ограничения версии 0.1
- Звонки: входящие можно только отклонить, исходящих нет (в TDLib нет аудио-движка).
- Оплата Premium и Stars: только просмотр и ссылка на @PremiumBot.
- Грузятся только последние 30 сообщений чата, подгрузки старой истории пока нет.
- Фото, видео и голосовые открываются во внешних программах, внутри терминала не показываются.
- Не работают: «Копировать», «Переслать», закрепление сообщения, поиск по чату, меню чата, эмодзи, микрофон.
- Большинство настроек (уведомления, данные, язык, тема, приватность) только запоминаются и в Telegram не отправляются.
- Нет: уведомлений о новых сообщениях, реакций, стикеров, форматирования текста, превью ссылок, опросов, секретных чатов, черновиков, папок Telegram, отключения звука чата, индикатора «печатает».
- Известная ошибка: нестабильное поведение мыши в некоторых терминалах (для диагностики есть `--mouse-debug`).

## Безопасность
Не публикуйте `config.ini` и папку `tdlib/`: по ним можно получить доступ к вашему аккаунту. Они указаны в `.gitignore`.
Telegram® принадлежит Telegram FZ-LLC; проект с ним не связан.

## Участие в разработке
Pull request'ы и issues приветствуются. Список того, чего не хватает, смотрите в разделе «Ограничения версии 0.1».
Перед отправкой изменений желательно проверить, что `cargo build --release` проходит без ошибок.
